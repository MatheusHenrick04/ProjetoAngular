# 💳 Fintech CRUD - Aplicação Web com Angular
Aplicação web do tipo CRUD (Create, Read, Update, Delete) voltada para o contexto financeiro/fintech, desenvolvida para praticar gestão de dados, manipulação de componentes e consumo de rotas com Angular e TypeScript.

## 📌 Funcionalidades
- **Gestão de Dados (CRUD):** Operações de criação, leitura, atualização e remoção de registos.
- **Componentização:** Arquitetura modularizada utilizando componentes do Angular.
- **Interface Reativa:** Formulários e navegação integrados.

## 🛠️ Tecnologias
- Angular (v19)
- TypeScript
- HTML5 / CSS3
- Node.js & npm
